প্রথমে Voice Model download করুন।
Offline ব্যবহারের নিয়ম
1) Internet ON → Voice Model Download
2) Download শেষ → একবার Generate করে পরীক্ষা করুন
3) Browser menu → Add to Home Screen / Install
4) এরপর Internet OFF করেও একই browser-এর এই app থেকে Generate করুন।
